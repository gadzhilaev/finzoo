# Формулы и правила экономики Finzo

Источник кода: `lib/core/profile/economy.dart`, `player_rules.dart`, `game_controller.dart`.

## Константы (`EconomyRules`)

| Имя | Значение | Когда |
|-----|----------|--------|
| `periodIncome` | 420 | Один раз за игровой период после старта/перехода дня |
| `periodIncomeLabel` | «Карманные от родителей» | Показ источника |
| `onboardingBalance` | = `periodIncome` (420) | После онбординга |
| `taskReward` | 20 | Первое успешное прохождение каждого practice id |

## Период

1. Старт периода / `startNextPeriod`: остаток `availableBalance` переносится; выдаётся новый доход 420 (`periodIncomeGranted`).
2. План бюджета: `necessary + wants + savings ≤ availableBalance`.
3. Покупки: списание с `availableBalance`, запись в `spentNecessary` / `spentWants`, история.
4. Копилка: перевод в `savedBalance` / `factSavings` с подтверждением; снятие с подтверждением.
5. Практика: виртуальные монеты внутри задания; на баланс — только `+taskReward` при первом id.
6. `finishPeriod` → итоги; рост: `growthPointsForPeriod` (нужное +2, план без превышения +1, накопления +1 — см. `PlayerRules`).
7. Стадии: little (&lt;6), growing (6–11), confident (≥12).

## Каталог покупок (факт)

- Кухня (нужное): 8 позиций, цены 25…70  
- Душ (нужное): 4 позиции, 50…75  
- Одежда (желания): 8 позиций, 80…200  
- Сумма «по одному»: 1680 &gt; 420 → нельзя купить всё за период.

## Что не является periodIncome

- Цена цели 300 (Наушники) — цена товара цели.  
- Фикстуры тестов `availableBalance: 280` — произвольный баланс сцены, не SoT.
