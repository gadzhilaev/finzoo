# Сценарий резервного видео ≤3 мин (REQ-P-004)

Основание: ТЗ §4.1 / §7.2 — резервная запись на случай сбоя live demo.  
Показывать **работающую сборку**, не слайды презентации.

Формат: MP4, портрет или захват эмулятора/устройства, без монтажа «фейковых» экранов.

## Тайминг

| Время | Что на экране | Что говорить (кратко) |
|-------|---------------|------------------------|
| **00:00–00:15** | Установка/иконка → первый запуск → Splash → Welcome | «Finzo — локальный питомец учит бюджету для детей 7–11.» |
| **00:15–00:40** | Возраст → имя → выбор образа → имя питомца | «Создаём профиль без аккаунта и сервера.» |
| **00:40–01:00** | Туториал книжки: 3 типа решений | «Нужное, желания, отложить — три решения каждого дня.» |
| **01:00–01:20** | Цель + план бюджета (3 суммы) | «Доход дня 420. План не больше баланса.» |
| **01:20–01:40** | Улица (hub): баланс, цель, статы | «Главный экран: ресурсы и следующие действия.» |
| **01:40–02:00** | Дом: покупка нужного + желание | «Покупка списывает монеты и влияет на питомца.» |
| **02:00–02:20** | Копилка / цель | «Накопления отдельно от „доступно“.» |
| **02:20–02:40** | Практика (1 задание) + объяснение + +20 | «Практика закрепляет навык; награда один раз за задание.» |
| **02:40–02:55** | Итоги периода / рост **или** страница книжки safety | «Решения → итог дня и рост Finzo / безопасность.» |
| **02:55–03:00** | Adult gate → демо/сброс (коротко) | «Взрослый раздел: демо и сброс с подтверждением.» |

Жёсткий лимит: **≤ 3:00**. Если не укладываетесь — убрать книжку **или** сократить онбординг (быстрый свайп туториала).

## Не включать в ролик

- Утверждения о физ. замере cold start / FPS без факта.  
- Слайды PPTX вместо UI.  
- Сцены с выдуманным балансом, противоречащим `EconomyRules` (420 / +20).
