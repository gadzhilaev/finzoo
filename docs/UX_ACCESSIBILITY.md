# UX / UI и доступность (Finzo)

Обоснование решений по §3.6 / §5 п.8. Только факты реализации.

## 1. Основной пользовательский flow

1. Splash → Welcome → возраст → имя → образ питомца (9 `starterLooks`) → имя питомца.  
2. `OnboardingTutorialPage` (6 экранов каркаса книжки): цель игры и **три типа решений** (нужное / желания / отложить).  
3. Короткое видео (`intro_outro`) → выбор цели → план бюджета дня.  
4. Hub — `StreetPage`: баланс, цель, статы, входы в бюджет / практику / историю / дом.  
5. Цикл периода: план → покупки (дом) → практика → копилка → итоги периода → рост → следующий день.  
6. Параллельно: книжка безопасности 1–6 (`BookPage`), Adult (`AdultPage` за gate `8+7`).

Маршрутизация: `WelcomePage` + `AnimatedSwitcher` / именованные экраны; без deep-link сервера.

## 2. Понятность навигации

- Hub показывает **что можно сделать дальше** кнопками/карточками (бюджет, практика, дом, цель), без длинной инструкции.  
- Возврат единообразный: `FinzoHitTarget` + IconButton «назад» на внутренних экранах (практика, цели, adult, budget).  
- Подсказка «три типа решений» доступна с улицы и бюджета (`MoneyTips`).  
- Adult: явные блоки «Прогресс», «Настройки», «Демонстрация», «Сброс».

## 3. Touch targets ≥ 48 dp

Реализация: `lib/core/theme/finzo_hit_target.dart`.

- `FinzoHitTarget.minSize = 48`.  
- `iconButtonStyle` — `minimumSize: 48×48`, `MaterialTapTargetSize.padded`.  
- `wrap` — непрозрачная зона 48×48 вокруг визуально меньшей иконки.  
Используется на: стрелки возраста, навигация практики/целей/сообщений/adult, вторичные кнопки улицы (высота ≥48).

## 4. Основной читаемый текст

- Книжка: `FinzoBookTokens.cardBodySize = 16` (основной текст карточек).  
- Заголовки карточек / промпты: 15 sp (`cardTitleSize`, `promptSize`) — вторичная иерархия, не основной body.  
- Шрифт: Rubik (`google_fonts` / bundled).  
- Токены книги и UI опираются на cream/ink контраст (`pageCream` / `ink` / `titleGreen`).  
ТЗ §3.6 формулирует **рекомендацию** «основной текст ≥16 sp», не жёсткий минимум для всех подписей.

## 5. Не только цвет

- Книжка: карточки «опасно / безопасно» — цвет **и** иконки ✓/✗ / текст подписи (`BookCardTone` + badge).  
- Практика / покупки: диалоги и пояснения текстом (`showFinzoFeedback`).  
- Состояние питомца после финансов: `showFinzoStateNote` — что изменилось + почему + какое действие.  
- Итоги периода: рост и сравнение план/факт с текстом и иконками, не только цветом полос.

## 6. Отключение анимаций

- Флаг профиля `animationsEnabled` (SharedPreferences).  
- Переключатель: `AdultPage` → настройки.  
- Runtime: `TickerMode(enabled: animationsEnabled)` в `WelcomePage`;  
  `AnimatedBookBackground`, `StreetSkyLayer`, переходы книжки/онбординга читают тот же флаг.

## 7. Звук

- Критичная информация **не** передаётся звуком: в прототипе нет SFX/audio-пакета.  
- Переключатель `soundsEnabled` сохраняется (готовность к будущим эффектам).  
- См. README / OPEN: REQ-U-007b — нужна ли обязательная реализация звуков (ТЗ требует отключаемость, не наличие).

## 8. Подтверждение значимых действий

- Сброс профиля — confirm в Adult.  
- Снятие с копилки — двухшаговое подтверждение в `SavingsDialog`.  
- Покупки / недостаточный баланс — диалоги с объяснением, без тихого списания.  
- Подтверждение плана бюджета: `GameController.confirmBudgetPlan`.

## 9. Возраст 7–11

- Короткие фразы в туториале, практике и MoneyTips.  
- Числа экономики целые (420 / +20 / цены каталога) без сложных процентов.  
- Adult gate отделяет настройки/демо/сброс от детского UI.  
- Нет стыда/штрафов за ошибку: практика даёт объяснение и повтор; неудачная покупка — текст «не хватает монет».

## Настройки доступности (перечень)

| Настройка | Где | Эффект |
|-----------|-----|--------|
| Анимации вкл/выкл | Adult | `animationsEnabled` |
| Звуки вкл/выкл | Adult | `soundsEnabled` (persist; SFX нет) |
| Сброс / демо | Adult + confirm | профиль |
