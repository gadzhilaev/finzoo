# Finzo

Мобильное приложение финансовой грамотности для детей 7–11 лет (конкурсный прототип «Питомец Финни» / продукт **Finzo**).

Ребёнок ведёт локального питомца-белку: планирует бюджет на игровой день, покупает нужное и желания, копит на цель, проходит практику и учит правила безопасности в книжке.

## Требования

- Flutter SDK (проект: `sdk: ^3.12.2`, проверено на Flutter 3.44.x)
- Android: целевая платформа конкурса; `applicationId` = `ru.gadzhilaev.finzo`
- Официальное ТЗ: `tz/TZ-Finny-hackathon.pdf` (текст: `tz/TZ-extract.txt`)

## Стек

- Flutter / Dart
- `shared_preferences` — локальный профиль
- `flutter_svg`, `google_fonts`, `video_player`
- Без сервера, без рекламы, без IAP

## Демо и сброс

Раздел **Для взрослых** (Messages → иконка взрослого **или** long-press имени на улице/в доме → пример `8 + 7 = 15`):

- **Демо-профиль** — учебный профиль с 5 игровыми днями (`GameController.loadDemoProfile`)
- **Сброс профиля** — очистка SharedPreferences + fresh profile (с подтверждением)

## Основные механики

| Механика | Где |
|----------|-----|
| Онбординг | возраст → имя → образ питомца → туториал 6 стр. → видео → цель → бюджет |
| Улица (hub) | баланс, цель, статы, план/практика/история |
| Бюджет дня | 3 направления: нужное / желания / копилка |
| Дом | покупки кухня/душ (нужное), одежда (желания) |
| Практика ×6 | 3 темы: бюджет / сбережения / платежи |
| Книжка 1–6 | урок безопасности (макеты обучение/) |
| Цели | ≥3 в каталоге (факт: 6) |
| Рост | 3 стадии по `growthPoints` |
| Adult | gate, прогресс, анимации/звуки, демо, сброс |

## Экономика (`EconomyRules`)

Источник истины: `lib/core/profile/economy.dart`

| Параметр | Значение |
|----------|----------|
| Доход периода | **420** («Карманные от родителей») |
| Старт онбординга | = 420 |
| Награда практики | **+20** только за **первое** прохождение каждого `practice_*` |
| Учебные монеты внутри практики | виртуальные, баланс «Доступно» не списывают |

Цены каталога и целей — отдельно (см. `docs/ECONOMY.md`).

## Persistence

Ключ SharedPreferences: `finzoo_player_profile_v1`  
Сохраняется: профиль, баланс, инвентарь, план, цель, practice IDs, growth, настройки `animationsEnabled` / `soundsEnabled`.

Страница книжки в памяти сессии (не persist) — это не требование PDF ТЗ.

## Звук

Официальное ТЗ §3.6 требует **возможность отключить** звуки/анимации и не передавать критичную информацию только звуком.

В прототипе **нет audio-пакета и SFX**. Переключатель «Звуки» сохраняется и готов к будущим эффектам; анимации реально отключаются (`TickerMode` + BG/облака/переходы).
